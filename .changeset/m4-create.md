M4: `create-roxyon-app` — `npm create roxyon-app my-app`. Templates `lumen`,
`lumen-baas` (RX SDK + `rxError` helper + a data-example view), and `node`
(dep-free HTTP server). LumenJS templates are scaffolded by `@lmjs/cli` and
overlaid. Every project gets `roxyon.json`, `AGENTS.md` (+ `CLAUDE.md` /
`GEMINI.md` / `.cursor/rules/roxyon.mdc` / `.github/copilot-instructions.md`),
`llms.txt`, `.roxyonignore`, and `dev`/`build`/`deploy` scripts.
