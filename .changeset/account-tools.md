The remote connector (mcp.roxyon.com) now offers Roxyon AI's account tools for the signed-in user: site files, cron and PHP settings (site_tools), shell commands in their hosting, DNS, SSL, mailboxes, database export/restore/SQL, backups and restores, cloud server actions, plans and invoices, Roxyon Base, newsletters, Engage and social posts. The list is loaded from Roxyon Engage at start; each call is made with the caller's own token.
